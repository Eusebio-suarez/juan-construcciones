# 1. Enfoque SEO general

La página debe posicionarse como un servicio local de construcción, electricidad, mantenimiento y remodelaciones en el Quindío.

El SEO debe enfocarse en búsquedas de personas que necesitan solucionar algo concreto, por ejemplo:

- Un arreglo eléctrico.
- Una remodelación pequeña.
- Un trabajo de obra blanca.
- Un trabajo de obra negra.
- Mantenimiento en una casa, apartamento, finca o local.
- Un maestro de obra o trabajador confiable en el Quindío.

La página no debe competir como una constructora grande. Debe competir como un servicio cercano, directo y confiable.

## Mensaje SEO principal

> Juan Gabriel ofrece servicios de construcción, electricidad, obra negra, obra blanca, remodelaciones y mantenimiento en el Quindío y alrededores, con atención directa y trabajos reales comprobables.

# 11. SEO para imágenes

Las imágenes son clave porque el proyecto depende mucho de trabajos reales.

## Reglas para imágenes

- Usar formato `.webp` cuando sea posible.
- Comprimir imágenes antes de subirlas.
- Usar nombres descriptivos.
- Agregar atributo `alt`.
- Usar lazy loading en imágenes que no estén en el primer pantallazo.

## Ejemplos de nombres de archivo

```txt
obra-blanca-juan-gabriel-quindio.webp
remodelacion-bano-armenia-quindio.webp
arreglo-electrico-quindio.webp
mantenimiento-casa-quindio.webp
obra-negra-muro-quindio.webp
enchape-bano-quindio.webp
pintura-casa-armenia-quindio.webp
```

## Ejemplos de textos alt

```html
<img src="/images/trabajos/obra-blanca-juan-gabriel-quindio.webp" alt="Trabajo de obra blanca realizado por Juan Gabriel en Quindío">
```

```html
<img src="/images/trabajos/remodelacion-bano-armenia-quindio.webp" alt="Remodelación de baño con enchape en Armenia Quindío">
```

```html
<img src="/images/trabajos/arreglo-electrico-quindio.webp" alt="Arreglo eléctrico residencial realizado en Quindío">
```

```html
<img src="/images/trabajos/mantenimiento-casa-quindio.webp" alt="Mantenimiento general para casa en Quindío">
```

## No usar alt genéricos

Evitar:

```html
alt="imagen1"
alt="trabajo"
alt="foto de obra"
```

# 14. SEO técnico básico

## Etiquetas base

Agregar en el `head`:

```html
<html lang="es-CO">
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<link rel="canonical" href="https://dominio.com/">
<meta name="robots" content="index, follow">
```

## Sitemap

Crear archivo:

```txt
sitemap.xml
```

Contenido base:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://dominio.com/</loc>
    <priority>1.0</priority>
  </url>
</urlset>
```

## Robots.txt

Crear archivo:

```txt
robots.txt
```

Contenido base:

```txt
User-agent: *
Allow: /

Sitemap: https://dominio.com/sitemap.xml
```
